# Ambulatory ECG Signal Quality Analysis (mSQI)

This directory contains the custom MATLAB implementation used to evaluate the signal quality of two e-textile electrodes over an 8-hour ambulatory recording. 

## Important Note on Datasets
Due to GitHub's file size limits, the raw 8-hour ECG datasets (400+ MB) are hosted externally. To run the analysis:
1. Download the raw data files from this secure link: https://drive.google.com/drive/folders/16AygdnMolP-7C7vQb2KNN5ZNHIZ5UZyx?usp=sharing
2. Place the downloaded `.txt` files in the same directory as the MATLAB scripts.
3. Run the main `.m` script.
